# Contributing

Thank you for your interest in contributing to **analytics-toolworks**.

This organization develops small, reusable, open-source tools for analytical work.

## Scope

Tools should automate common mechanics without taking analytical judgment away from the user.

This project helps provide common functions or recurring code blocks to help
focus on the analytics decisions parts of projects.

## Principles

- Keep tools focused and independently useful.
- Prefer established libraries over reimplementing existing capabilities.
- Keep implementations transparent and inspectable.
- Use clear analytical terminology.
- Keep dependencies limited to what the tool actually needs.

## Participating

- Follow the project Code of Conduct.
- Keep contributions focused and understandable.
- Open an issue before proposing a substantial new capability.
- Follow repository-specific contribution requirements when provided.
